# CAN-based-Intelligent-Bus-Accident-Prevention-and-Automatic-Braking-System-using-LPC2129
CAN-Based Vehicle Safety and Alert System developed using embedded systems concepts. The project enables real-time communication between vehicle nodes through the Controller Area Network (CAN) protocol to monitor critical events and transmit safety alerts efficiently, ensuring reliable and low-latency data exchange.
This project implements a Controller Area Network (CAN) based Vehicle Safety and Alert System using the LPC2129 ARM7 microcontroller. The system enables reliable real-time communication between multiple vehicle nodes through the CAN bus, allowing safety-critical information to be transmitted efficiently with minimal latency.

The project demonstrates the implementation of CAN communication for automotive applications, where sensor data and warning messages are exchanged between nodes to improve vehicle monitoring and driver awareness. The LPC2129's built-in CAN controller is utilized for message transmission, reception, arbitration, and error handling, ensuring robust communication in a distributed embedded system.

Features
CAN protocol implementation using LPC2129
Real-time transmission and reception of safety messages
Multi-node communication architecture
CAN frame configuration and message arbitration
Error detection and fault-tolerant communication
Embedded C programming for automotive applications
Scalable design suitable for vehicle monitoring systems
